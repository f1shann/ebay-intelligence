MARKETPLACE INTELLIGENCE PLATFORM (EBAY UK ARBITRAGE)
Dual-engine Python asset using eBay Browse API, eBay Marketplace Insights API and SQLite to track ~25 high-opportunity products.
________________________________________
Core Engines
Engine 1: DISCOVER (Market Scout & Maintenance Radar)
•	Objective: Finds new and audits existing target products using historical sold data from marketplace insights api
•	Macro sell through rate if relevant
•	Sales Liquidity: Minimum 15 sales / 30 days.
•	Statistical Sanitization (IQR): Filters outliers outside 1.5 × IQR (scams, bundles, broken parts).
•	Coefficient of Variation (CV): Rejects markets with low price variance.
•	Saves products in a database (not sure how this is going to work yet but likely going to have category, product identifier, the stats we’ve talked about, median)
Engine 2: HUNT (Live Arbitrage Sniper)
•	Objective: Scans live "Buy It Now" streams; alerts via Discord Webhook with a clickable link.
•	Pricing Standardization: Factors in 2026 UK Buyer Protection Fees; standardises all item totals with full shipping costs.
•	Text Token Confidence Scorer: Eliminates false positives (e.g., "box only", condition contradictions) via negative token filtering.
•	Percentage Deviation Trigger: Fires if 100(Database median-live cost)/ database median is greater than target profit margin
•	Maybe looking at seller feedback score
•	Intelligent Best offer scanner
•	Potentially 10 minutes ago limit as good listings are normally sniped within 10 minutes im not too sure about this though 
________________________________________
System Extensions
A. Spike & Drop Filter (Product Finding)
•	Logic: Tracks 7-day vs. 30-day rolling medians. Blacklists items with plummeting price velocity to prevent buying declining stock.
B. Advanced AI Verification Layer
•	Logic: Extracts title, description, and metadata to detect deep-text defects or deceptive listings.
•	Infrastructure: Uses zero-cost, offline Ollama (Llama 3 8B / Phi-3). Forces rapid, binary classification via structured JSON.
C. Media Ingestion
•	Logic: Asynchronously downloads primary high-res images (imageUrls) to a local /assets/ directory using Python requests and shutil.
•	Payload: Attaches the image directly to the Discord Webhook for immediate inspection and one-tap re-use.
